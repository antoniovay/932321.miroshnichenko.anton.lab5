# Лабораторная работа №5. DOM и взаимодействие с элементами страницы

## Задание
**Реализовать интерактивные функции:**
- Поиск элементов через getElementById, querySelector, querySelectorAll.
- Манипуляции с DOM: изменение текста, атрибутов, классов; добавление/удаление
элементов.
- Переключение темы (светлая/тёмная) по кнопке.
- Скрытие/показ блоков по клику.
- Обработка ошибок: проверка существования элемента.
- Сохранение состояния в localStorage: при добавлении/удалении элементов и
переключении темы сохранять данные; при загрузке страницы восстанавливать их.

**Вариант 14. Тема «Дизайнер и визуализатор» (палитра цветов с названиями)**
Контент: плитки цветов (цвет через background-color, название, кнопка «Удалить»).
Логика: «Добавить цвет» запрашивает HEX-код и название, создаёт плитку. Кнопка
«Очистить палитру» удаляет все плитки. Переключение темы, скрытие палитры. Проверка
элементов.

## Результат
- Все методы поиска элементов использованы.
- Манипуляции с DOM работают без перезагрузки.
- Интерактивность реализована.
- Обработка ошибок присутствует.
- Состояние (добавленные элементы и выбранная тема) сохраняется в localStorage и
восстанавливается при перезагрузке.
